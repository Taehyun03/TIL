KAI 목표 스펙 커리큘럼 (네트워크 보안 + 항공)
2026년 9월 30일 · @김태현
전체 방향
최종 목표는 한국항공우주산업(KAI) 입사이고, 축은 "네트워크 보안 + ML 탐지 + 항공 SW"로 잡는다. 졸업 전까지 논문 3편 이상(그중 1편은 드론·항공 보안), 보안 대회 입상 1회, BoB 수료를 목표로 한다.
• 깊이: IoT Flooding IDS 연구를 드론 네트워크 보안으로 확장해 학회 논문으로 만든다
• 차별화: 보안만 아는 사람이 아니라 항공 SW 표준과 임베디드 C까지 아는 사람이 된다
• 넓이: 공격 원리, 리눅스, 웹 보안 기초를 대회 준비로 채운다
• 증명: 모든 공부는 논문, 수상, GitHub, 블로그 중 하나로 흔적을 남긴다
• 안전장치: 준비의 70%는 어디서나 통하는 기초·보안 역량, 30%만 KAI·항공 특화로 둔다
원칙은 학기마다 "공부 1개 + 결과물 1개"다. 한 학기에 대회를 여러 개 흩어서 나가기보다, 하나를 끝까지 해서 결과를 남기는 쪽이 스펙으로 훨씬 강하다.
일정은 예년 기준 대략적인 시기라서, 지원 전에 각 공식 공지를 꼭 다시 확인해야 한다.
목표 기업: KAI
KAI는 사천 본사라 진주에서 가깝고, 보안과 항공을 함께 아는 인력이 드물어 지역 인재에게 유리한 목표다. 대졸 신입은 성과급 포함 대기업 상위권 연봉이고, 연구개발 직무는 석사 신입도 많이 뽑는다.

기초 다지기 (모든 계획의 바닥)
대회나 논문보다 먼저 전공 기초 6개를 2학년 겨울방학까지 "설명할 수 있는 수준"으로 채운다. 기초가 얇은 상태에서 스펙만 쌓으면 면접이나 연구 미팅에서 바로 드러나고, 반대로 기초가 잡히면 이후 공부 속도가 2~3배 빨라진다.
순서가 중요하다. 아래 표는 위에서부터 차례로 쌓이는 구조라서, 막히면 한 칸 위로 돌아가면 된다.

• 연구 시간에 모르는 용어가 나오면 바로 노트에 적고, 주말에 한꺼번에 찾아 정리
공부법 원칙
• 읽기만 하지 말고 손으로 친다: 책의 예제 코드를 복사하지 말고 직접 타이핑
• 설명해봐야 안다: 공부한 걸 블로그나 노트에 "친구에게 설명하듯" 적어보면 모르는 부분이 드러난다
• Claude 같은 AI는 답이 아니라 질문 상대로: 코드를 받아쓰기보다 "왜 이렇게 동작해?"를 물어보는 용도로 쓴다
• 완벽주의 금지: 한 과목을 100% 끝내고 넘어가지 말고, 70% 이해했으면 다음으로 가고 필요할 때 돌아온다
