2026.10.01 배운 git 명령어 정리
- git clone "주소" -> github 저장소를 내 컴퓨터로 복사 (처음 한번만해도 되고 지금 명령어를 입력하는 내 위치에 생김. pwd 습관화하기)
- git status -> 뭐가 바뀌었고 뭐가 담겼는지 확인용
- git add . -> 바뀐 파일을 저장 대상으로 담기
- git commit -m "메시지" -> 담은 것을 하나의 기록으로 확정
- git push -> 내 커밋을 github에 올리기 
- git pull -> github의 최신 내용을 내 컴퓨터로 가져오기
- git log --oneline -> 지금까지의 커밋기록 한줄씩 보기

- Q) 커밋이 뭔가?
- A) 어느 시점에 누가 뭘 어떻게 바꿨고 그 바꾼것에 대해 남긴 메시지 -> 이전 커밋으로 돌아가기 이런거 가능
- Q) git clone 한 이후에는 아예 연결이 된거라 이후부터는 pull만 하면 팀원들이 고친게 다 넘어오는가?
- A) 맞음. 연결은 한번만. 대신 팀원이 push 한 내용들만 pull 가능.
